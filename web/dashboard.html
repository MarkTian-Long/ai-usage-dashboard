统计说明

数据来源与范围

  • 仅扫描本机 Codex 的会话与归档会话 JSONL。
  • 原始 JSONL 始终只读，不上传数据。
  • Token 与请求日期按 Asia/Shanghai 归属。首次打开默认显示当前统计月和任务用量（含子代理）；可切换自动安全审查或全部 Token。日期、统计范围、模型与推理强度筛选共同作用于 Token 总览和请求与效率。
  • 自动安全审查是自动授权安全检查，单独归类；普通子代理归入任务用量。各线程的模型与推理强度分别归属，不用父聊天设置覆盖子线程。
  • 模型占比按当前筛选的原始 Token 计算，不代表官方套餐额度占比，也不能据此换算套餐或付费额度。
  • Token 来源包含消耗统计事件与逐请求消耗记录；逐请求记录只补计缺少对应统计事件的请求，并按响应去重。
  • 预设日期范围随快照截至日推进；本月指自然月初至截至日。手动改日期会切到自定义，并在重载和自动更新后保留。

刷新机制

  • 刷新按源文件长度和最后修改时间复用本地缓存，新增或修改的文件才重新解析。
  • 页面数据通过本地接口异步加载；后台刷新完成后，已打开页面会自动检测并更新。
  • 刷新期间继续展示上一版完整数据；仅在新版数据加载成功后显示刷新完成。
  • 当前后台维护每分钟检查、每小时汇总，页面每 30 秒检查新版本。增量缓存按文件工作：仍枚举文件信息，仅读取有变化的源文件。

计算方式

  • Total = Input + Output；Fresh Input = Input − Cached Input。
  • Cache、Fresh、Output 互斥；Reasoning 属于 Output，不重复计入 Total。
  • 请求按实际线程与 Turn 合并；会话数按实际线程去重，包含所选范围内的子代理线程。每日请求量包含已完成、报错和未完成请求。
  • 请求有开始日期时按开始日期归属；完成时长包含思考、生成、工具执行与等待。
  • 首响和完成时长分别排除缺失值；百分位取排序后位置 floor((n − 1) × p) 对应的样本。

Skill 说明读取

  • 这是可观测代理指标，不代表 Skill 实际调用或任务成功；可用 Skill 清单和对话中提及名称均不计入。
  • 按会话、轮次与 Skill 去重，仅统计主任务（会话），排除 guardian 和子代理，活动与归档日志不重复计数。
  • Skill 日期按 Asia/Shanghai，含首尾，与 Token 筛选独立。近 7 天、近 30 天、本月和全部历史随快照更新，自定义日期保持固定。
  • 读取轮次是一项 Skill 被读取的轮次数；涉及任务（会话）是读取过该 Skill 的不同主会话数。
  • 总览跨 Skill 合并轮次与主任务；Skill × 轮次按每项 Skill 分别计。观测清单不是完整安装清单，观察项只用于人工复核。
