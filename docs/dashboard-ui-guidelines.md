# 仪表盘筛选与说明展示规范

适用范围：本项目的 Token 总览、请求与效率、Skill 说明读取及后续新增页面。依据 2026-09-28 用户对筛选一致性和中文可读性的要求制定；这是项目内界面约定，不修改用户级 Skill、权限或统计规则。

## 筛选条

| 项目 | 统一约定 |
| --- | --- |
| 日期入口 | 使用“日期范围”下拉框，选项顺序为今天、近 7 天、近 30 天、本月、全部历史、自定义。开始日期、结束日期紧随其后。 |
| 日期口径 | Asia/Shanghai，自然日，包含首尾；快捷范围锚定数据快照截至日，不锚定浏览器所在时区或尚无数据的将来。近 N 天为截至日及之前 N−1 天；本月为截至日所在月的月初至截至日。 |
| 自定义 | 选择自定义时保留当前日期，手动改任一日期即切换为自定义。开始日晚于结束日、日期缺失或超过允许截至日时给出明确提示，不把无效输入显示成真实的零数据。 |
| 全部历史 | 使用当前统计域可观测数据的历史起点至快照截至日；不声称覆盖日志缺失之前的全部历史。 |
| 字段顺序 | 日期在前，业务维度与搜索居中，排序/趋势指标等展示设置在后，最后是“重置筛选”。窄屏按此顺序换行。 |
| 选择与搜索 | 下拉框选择后即时生效，搜索输入即时生效，不另设“查询”。始终保留可见标签，不仅依赖占位文字。 |
| 全部选项 | 使用“全部模型”“全部推理强度”“全部来源”“全部观察项”等有上下文的完整名称。 |
| 重置 | 按钮统一称“重置筛选”，只恢复该筛选组的日期、业务维度及展示设置，不重置其他统计域。附近说明恢复到哪个默认范围。 |
| 状态保存 | 切页、重载和数据刷新保留筛选。日期预设随新快照推进，自定义日期固定；旧版只保存日期的 Token 视图按自定义迁移，避免覆盖用户已选历史区间。 |

## 有意保留的差异

- Token 总览与请求/效率共享一组筛选，默认“本月”，服务日常月度用量观察；Skill 使用独立筛选，默认“近 30 天”，服务跨月观察与定期审计。
- Token 的模型、推理强度和趋势指标，与 Skill 的名称/简介、来源、观察项、排序具有不同语义，不为了控件数量相同而添加无意义字段。
- 趋势指标只改变 Token 图表所展示的度量，排序只改变 Skill 清单顺序；它们不是额外的数据排除条件。
- “本期未观测”仅指历史曾有可识别记录、当前区间没有记录；“未知来源”仅指位置无法可靠分类；都不表示没有安装、从未使用或质量差。

## 外观与可访问性

两组筛选复用 `.filters`、`.control`、`.btn` 的尺寸、字体、圆角、边框和焦点样式，日期/选择/搜索控件对齐。禁用状态明确可见；无可用数据或旧快照不支持的操作不可假装可用。桌面和 390px 窄屏均不得出现页面横向溢出、标签遮挡或控件裁切。键盘可操作，读数不能只靠悬停或颜色。

## 简介、来源与中文释义

Skill 标识用于关联统计，原始名称/简介来自当前本地元数据。中文释义只改善阅读，不修改源 `SKILL.md`、触发规则或统计记录。默认展示匹配的中文释义，展开可查看原文；中文原文不重复翻译。搜索同时覆盖标识、名称、原文和中文释义，导出同时保留原文及释义并说明其性质。

本地释义位于 `web/skill-descriptions.zh-CN.js`，按来源、Skill 标识和完整原文精确匹配。原文或来源改变时旧释义失效，回退原文；新增英文描述未经整理时也回退原文。不调用在线翻译或后台模型，不推断未知 Skill 的用途。

来源标签是路径分类，不是作者身份、可信度、优先级或成功状态。页面和数据中不加入本机用户名/绝对路径；路径说明使用通用目录模板，具体本机位置只在用户授权的本地说明中解释。

## 变更验收

新增当前目录功能沿用筛选规范：清单范围默认历史观测，可选择当前目录或联合对照；用途分类明确为规则候选。当前目录资料日期独立于历史筛选日期，找不到不等于卸载，目录数量不混入读取量。旧快照缺少目录数据时相关操作禁用或明确提示未提供，不按空目录推断。

任务组合属于人工选择辅助：只选当前有可用且无冲突说明的 Skill，同身份多份定义需先复核，跨来源同名可明确选择。失效组合列出具体项目并支持移除；复制前可查看只读草稿。名称和身份可保存到本浏览器，任务目标与口令草稿不持久化。最多保存 20 组，同名更新，达到上限时提示而非静默删除旧组合；删除仅影响所选浏览器组合。存储受限时明确提示仅在本页暂存。生成、复制与保存不得表述为已调用或成功执行。现有总控 Skill 能覆盖的流程优先复用，避免模板建立平行的专家规则。

1. 改筛选后检查边界日期、默认/自定义、重置、跨页隔离、旧视图迁移、刷新后保留，以及卡片/图/清单/导出是否共享相同范围。
2. 改释义后检查原文匹配、来源隔离、变更后失效、原文可访问、中文搜索与导出，统计数字不受语言显示影响。
3. 完成 Frontend 与 UI Contract 检查；影响生成打包时检查生成页面并通过既有 API 刷新验证 `ready`。在真实浏览器检查桌面与 390px 下的相关控件，不仅核对 DOM 标记。
4. 修改规则时同步更新本文件及对应测试；统计语义仍以 `docs/skill-read-metrics.md` 和生成器为准。
